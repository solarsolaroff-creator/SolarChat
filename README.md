# SolarChat
SolarChat — это open-source веб-мессенджер, построенный на чистом HTML/CSS/JS и Firebase. Без установки, без регистрации по email, без лишнего. Что умеет:   Групповой чат — общайтесь со всеми сразу, сообщения приходят мгновенно   Личные сообщения — начните диалог с любым участником одним нажатием   Мульти-аккаунты
